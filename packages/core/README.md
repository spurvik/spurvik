# packages/core

Build from source. This directory is not published on npm under a scoped name. Its code is bundled into the published `spurvik` and `spurvik-sdk` packages.

Hashing, provenance records, and the hash-chained audit log shared by the SDK and the control plane. A matching chain shows the stored rows still link. It is not externally anchored.

See the root `LICENSE`. This package does not depend on `apps/web`.
